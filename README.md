# NumPy Analyzer

NumPy Analyzer is a Python-based interactive console application that helps you explore and practice **NumPy array operations** in a structured, menu-driven way.  
It’s designed for students, developers, and data science enthusiasts who want hands-on experience with arrays and numerical computations.

---

## ✨ Features

- **Create Arrays**
  - Build 1D, 2D, and 3D arrays interactively
  - Generate random arrays with reproducible seeds

- **Mathematical Operations**
  - Addition, Subtraction, Multiplication, Division
  - Shape validation ensures safe operations

- **Indexing and Slicing**
  - Access elements by index
  - Slice arrays using Python slice notation

- **Combining and Splitting**
  - Concatenate arrays
  - Split arrays into multiple sections along a chosen axis

- **Searching, Sorting, Filtering**
  - Search for values and return indices
  - Sort arrays along any axis
  - Apply custom filter conditions (e.g., `lambda x: x > 10`)

- **Statistical Operations**
  - Sum, Mean, Median, Variance
  - Correlation (restricted to 1D/2D arrays)
  - Percentile (custom percentile input with default fallback to 50)
  - Minimum and Maximum

- **Array Shape Overview**
  - Display the shape of all arrays created so far
